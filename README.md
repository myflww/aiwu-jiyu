# 一键领养大肥鱼

**爱屋及鱼 · myflww 制作的 Windows 桌面陪伴控制台**

把蓝色鲸鱼娘接进 QQ，在一个窗口里管理聊天、长期记忆、插件和电脑操作权限。完成首次设置后，点“一键开启”，就能去 QQ 找她。

## 能做什么

| 功能 | 用法 |
| --- | --- |
| QQ 聊天 | 使用 QQ 小号登录，填写主人主号；好友和群聊按名单开放 |
| 插件开关 | QQ 原生表情、长期记忆、电脑操作、主动陪伴与情绪、大肥鱼表情包分别启停 |
| 长期记忆 | 连接本机爱之屋，选择记忆库，登记要保存的 QQ 会话 |
| 电脑操作与作品箱 | 分级授权文件、命令工具；最高权限可查看控件、按需截屏、点击输入与打开桌面应用 |
| 实时内存 | 首页显示系统物理内存、应用进程分项和最近 60 秒走势，首页可见时每 2 秒采样 |
| 四种立绘 | 日常手绘、蓝白水手、水手 Q 版、经典 Q 版，在设置里切换 |
| 日常管理 | 托盘运行、开机启动、快速登录、服务日志和软件更新 |

插件启用与能力授权分别管理。打开“电脑操作”插件后，仍需设置工作目录并明确授权；打开“长期记忆”插件后，仍需连接记忆库和会话。切换立绘只改变界面造型。

对话节奏与陪伴、大肥鱼表情包、QQ生活与联网搜索均随下载附带。全新安装默认开启连续消息收集与群聊按需回应；主动聊天、活动感知、表情和QQ生活能力仍由用户选择，已有停用选择保留。鲸鱼娘自然中文口吻、主动聊天、自然分段、情绪表达和活动概况感知可分别开启；日常提供安静陪伴、自然朋友、活泼陪伴三种节奏，仍只联系已确认私聊会话的主人，并遵守所选预算和免打扰。预设数值可调整，不宣称经用户实验验证为最佳；已有设置继续保留。活动感知只读取应用名称和闲置概况，不记录按键或持续截图。表情插件离线附带六张原创贴纸和二十四张按上游非商业条件分享的社区动图，支持个人图导入、收藏、本地试选和独立素材更新，与 QQ 原生小表情分开管理。

插件页可快捷打开本机 AstrBot、NapCat 后台。诊断日志在启动及每十分钟检查：空闲后超过 5 MB 保留最新 1 MB，连续七天未写入清空；聊天和记忆不在清理范围内。

1.4.0 将主动问候接入真实会话历史、爱之屋记忆和表情／分段处理；首页和QQ的“今天”陪伴调整均在所选时区当天结束。增加只读小家体检、真实电脑工具进度、有限范围的备份恢复，以及由运行事实驱动的五种新状态插画。六张自有表情的衣橱设定采用白衬衫配铅笔裙与黑色连裤袜、黑色针织修身裙、青绿旗袍、黑夹克配格纹裙、碎花裙、针织开衫；二十四张社区授权GIF保留原图和原许可。操作入口与边界见 [1.5.0 使用指南](docs/1.5.0使用指南.md)，设计依据见 [陪伴连续性](docs/陪伴连续性研究与实现.md)、[自检恢复与操作记录](docs/自检恢复与操作记录.md)和[表情图库](docs/表情图库研究与实现.md)。

## 第一次领养

准备 **Windows 10 2004 或更新版本 / Windows 11 的 64 位电脑、一个 QQ 小号、DeepSeek API Key 和可用网络**。首次安装会下载运行环境，对话请求由你配置的模型服务处理，并按该服务的规则计费。

1. 从发布页下载 Windows x64 完整包，解压后打开 `爱屋及鱼.exe`。需要桌面快捷方式时，运行包内的“安装到桌面.cmd”；若发布页提供安装程序，也可使用安装程序。
2. 跟随向导选好运行数据目录，等待聊天服务与 QQ 连接环境准备完成。
3. 填写 DeepSeek API Key 和模型，在手机 QQ 切到小号后扫码登录。
4. 填写你日常聊天使用的 QQ 主号，完成设置。在首页确认在线，再用主号给小号发消息。

**长期记忆需要另装[爱之屋](https://github.com/myflww/love-house/releases)。** 本程序不会把“开启记忆插件”当成已经安装了记忆服务。装好爱之屋后，还要启动服务、选择记忆库、登记会话，并在爱之屋内配置记忆整理模型。完整步骤见[使用说明](docs/使用说明.md#连接长期记忆)。

插件显示“已保存，重启对话服务后生效”时，点击“应用更改 · 重启对话”。这会短暂停止对话服务，QQ 连接保持在线。

## 数据与运行方式

聊天由 AstrBot 和 NapCat 协作完成，记忆由爱之屋提供。运行环境和配置保存在本机，模型对话及记忆整理会请求你配置的 API 服务。

爱屋及鱼默认数据目录为 `%LOCALAPPDATA%\Dafeiyu`，首次设置可以选择其他位置；爱之屋默认数据目录为 `%LOCALAPPDATA%\LoveHouse`。作品保存在设置中的工作目录。备份时请分别保存这些目录，详细位置和恢复注意事项见[数据备份与卸载](docs/使用说明.md#数据备份与卸载)。

关闭窗口通常会收进系统托盘，聊天服务继续运行。首页“一键关闭”会停止聊天与 QQ 连接；托盘也有“退出并停止服务”。
