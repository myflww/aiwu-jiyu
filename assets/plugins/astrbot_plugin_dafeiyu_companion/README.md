# 大肥鱼陪伴

随爱屋及鱼附带，默认停用。将主动聊天、互动情绪和电脑活动概况合并为一个可选插件，避免多个插件重复问候。

- **自主搭话**：不是主人逐次提醒，也不需要创建 cron。插件启用后由独立后台每分钟检查条件；先与主人在 QQ 私聊至少一次，才保存已经真实出现的私聊会话。主动机会到来并通过概率、预算和减扰条件后，使用当前会话的模型、人格和近期普通文本，自行从延续话题、轻松小点子、应景生活话题等角度发起短消息。轮换话题并避免重复上一句；不虚构现实经历，不催回复，不调用电脑或其他工具。模型可选择暂不打扰。关闭插件会停止任务。
- 发送名额和间隔先保存在本机再请求模型；保存失败不生成、不发送。失败或送达结果不确定时保留这次名额，避免重启后重复联系。
- **情绪陪伴**：根据近期互动调整大肥鱼的表达风格，这是角色状态模拟，不代表真实意识或对用户心理健康的诊断。只保存有限状态，不再复制一份聊天档案。
- **大肥鱼口吻**：可选的傲娇甜口与自然中文表达，承接真实对话，减少固定欢迎词和客服式收尾。只追加表达偏好，不覆盖用户现有人格；只要求用户可见的简短中文说明，不要求或暴露隐藏思维链，不声称能控制模型内部思考语言。与主动聊天、情绪和活动感知分别开关。
- **自然分条聊天**：独立开关，默认关闭。可选择偶尔或更常分条；仅将主人 QQ 私聊中适合的普通文本拆成少量完整句段。代码、链接、工具结果、混合媒体等保持完整。已有 AstrBot 原生分段、语音或文字转图等流程时优先让原流程处理；新消息到来、权限关闭或发送不确定时停止尚未发出的尾段。主动短消息保持单条发送。
- **活动概况**：用户明确启用后，只读取前台进程的应用名、闲置时间和离开/回来。每分钟最多读取一次；概况可附到用户当前模型请求中。不获取窗口标题、键盘输入或屏幕内容，不后台截图。
- **按需看屏幕/操作电脑**：由独立的电脑操作插件和最高权限控制，此插件没有屏幕采集或键鼠操作能力。

目标只来自已核对的主人私聊，群聊、陌生人、机器人自身和其他平台不会成为主动问候目标。没有模型、会话、人格或有效平台时跳过，失败时不发送固定广告式消息。主动生成会产生所选模型的 API 用量。

与爱之屋长期记忆分工：爱之屋负责经历存档和召回；本插件只保存主人会话标识、时间、每日计数、有限角色状态和最近一句主动问候。最近问候作为下一轮的临时提示，避免并发覆盖 AstrBot 的聊天历史。私有状态位于 AstrBot 的 `data/plugin_data/astrbot_plugin_dafeiyu_companion/state.json`，不随发布包上传。

桌面端可查看独立的公开运行状态：开关关闭、等待真实私聊、QQ 连接不可用、免打扰、下一次机会与范围、有效概率、连续未回应次数、暂停原因、每日名额，以及上次机会/生成/发送结果。`last_trigger_source=background_idle` 表示来自本机后台主动机会；`initiated_count` 只累计适配器已接受的发送，不表示主人已阅读。`last_receipt=delivery_uncertain` 表示送达未知，保留名额和未回应次数，避免重发。`runtime.json` 不包含 QQ、会话标识、聊天正文、模型凭据或错误详情；心跳过期时显示任务未运行。不能把模型在聊天中的自述当作发送结果。

## 高级设置与参考值

不存在经过本项目实验验证的“最佳30分钟/每天3次”。以下参考来自公开项目的具体配置和代码，适合当作个人调节的起点，不能当作科学结论。新装默认采用 Aurabot 的随机60–180分钟、私聊安静40分钟、每日4次、23:00–08:00免打扰；概率和未回应减扰是本适配提供的独立选项。来源、提交、默认值差异见 `SOURCES.md`。

| 设置 | 含义与范围 |
| --- | --- |
| `schedule_mode` | `fixed` 固定机会间隔，或 `random` 在区间内抽取下一次机会。 |
| `interval_minutes` | 固定模式5–1440分钟。旧版显式设置保留为固定模式。 |
| `min_interval_minutes` / `max_interval_minutes` | 随机最短5–1440、最长5–2880分钟；最长不得小于最短。随机点落盘，重启不会每分钟重新抽签。 |
| `idle_minutes` | 距真实主人私聊至少安静0–1440分钟，与机会间隔同时满足。 |
| `trigger_probability` | 每次机会的基础概率0–100%；0不调用模型。落空不消耗生成预算，重新安排下一次机会。 |
| `unanswered_decay_percent` | 每次未回应后概率降低0–100%；有效概率=基础概率×(1-降低比例)^连续未回应次数。0关闭衰减。新装默认50%为可调减扰选择，没有宣称来自上游的实验最佳值。 |
| `max_unanswered` | 连续未回应达到1–20次时暂停，主人真实私聊后恢复；0不限制。新装4次参考 AstrBot 主动消息插件的未回复闸门。送达不确定也保留一次。 |
| `daily_limit` | 所选时区内每日模型生成尝试0–20次；0不生成。模型沉默、生成失败或送达未知仍保留已占用名额。 |
| `quiet_start` / `quiet_end` | 0–23小时；相等表示不设免打扰。 |
| `timezone` | `local` 跟随本机、`Asia/Shanghai` 北京时间UTC+8、`UTC` 世界时；Windows无需额外IANA时区数据库。 |
| `session_expiry_days` | 1–365天无主人私聊后暂停；0不限制。默认7天保留原版兼容保护，可按偏好调整。 |

“填入 Aurabot 参考值”只填随机区间、安静时间、日预算、时区及免打扰，保存后才应用，不改其他能力、概率或未回应选项。已有显式旧设置不自动覆盖；没有 `schedule_mode` 的旧 `interval_minutes` 迁移为 `fixed`，并让新增安静、概率衰减和未回应暂停限制保持关闭，避免偷偷改变旧规则。你可以再自行选择随机模式及高级参数。

这里显示的是**下一次机会**，不是承诺发送的时刻：免打扰、概率落空、无人回应、模型不可用、用户新消息或模型选择沉默都可能继续推迟。调整时先观察状态里的真实机会结果与发送回执，再按个人偏好和API预算决定频率。

尚未在桌面保存陪伴偏好的老用户，会采用已有 AstrBot WebUI 插件设置，避免启动时被默认关闭值覆盖；首次明确保存桌面设置后以桌面设置为准。插件宿主开关与各项能力仍需分别开启；新下载的用户默认停用。后台轻量任务可在宿主开启时等待设置，关闭的能力不采样、不请求模型、不联系用户。
