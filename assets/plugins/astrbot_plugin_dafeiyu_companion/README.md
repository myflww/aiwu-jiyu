# 大肥鱼陪伴

随爱屋及鱼附带，默认停用。将主动聊天、互动情绪和电脑活动概况合并为一个可选插件，避免多个插件重复问候。

- **主动问候**：先与主人在 QQ 私聊至少一次，才保存已经真实出现的私聊会话。使用当前会话的模型、人格和近期普通文本生成简短消息，不调用电脑或其他工具。默认间隔至少120分钟，每日最多3次，23:00–08:00免打扰；7天未互动后暂停主动问候。关闭插件会停止任务。
- 发送名额和间隔先保存在本机再请求模型；保存失败不生成、不发送。失败或送达结果不确定时保留这次名额，避免重启后重复联系。
- **情绪陪伴**：根据近期互动调整大肥鱼的表达风格，这是角色状态模拟，不代表真实意识或对用户心理健康的诊断。只保存有限状态，不再复制一份聊天档案。
- **大肥鱼口吻**：可选的傲娇甜口与自然中文表达，承接真实对话，减少固定欢迎词和客服式收尾。只追加表达偏好，不覆盖用户现有人格；只要求用户可见的简短中文说明，不要求或暴露隐藏思维链，不声称能控制模型内部思考语言。与主动聊天、情绪和活动感知分别开关。
- **活动概况**：用户明确启用后，只读取前台进程的应用名、闲置时间和离开/回来。每分钟最多读取一次；概况可附到用户当前模型请求中。不获取窗口标题、键盘输入或屏幕内容，不后台截图。
- **按需看屏幕/操作电脑**：由独立的电脑操作插件和最高权限控制，此插件没有屏幕采集或键鼠操作能力。

目标只来自已核对的主人私聊，群聊、陌生人、机器人自身和其他平台不会成为主动问候目标。没有模型、会话、人格或有效平台时跳过，失败时不发送固定广告式消息。主动生成会产生所选模型的 API 用量。

与爱之屋长期记忆分工：爱之屋负责经历存档和召回；本插件只保存主人会话标识、时间、每日计数、有限角色状态和最近一句主动问候。最近问候作为下一轮的临时提示，避免并发覆盖 AstrBot 的聊天历史。私有状态位于 AstrBot 的 `data/plugin_data/astrbot_plugin_dafeiyu_companion/state.json`，不随发布包上传。
