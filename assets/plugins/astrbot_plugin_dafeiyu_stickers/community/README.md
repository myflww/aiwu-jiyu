# 社区表情投稿

软件中的个人图库只留在本机。选择一张图、预览公开内容并确认授权后，可以用自己的 GitHub 账号提交 PR，也可以导出投稿 ZIP 后手动上传。

投稿不会直接合入主分支。维护者审核图片、描述、使用场景、避用场景、作者署名与分发权后收录；后续发行版更新随附插件清单，下载者即可拥有已收录的图片。未审核的 PR 不会自动进入其他用户的图库。

每份投稿目录为 `submissions/<64位内容指纹>/`，仅允许三个文件：

- `image.png`、`image.jpg`、`image.webp`、`image.gif` 中的一种。
- `metadata.json`：schema_version=1，包含标题、心情、标签、说明、适用/避用场景、作者署名、CC-BY-NC-4.0 许可，以及图片文件名、MIME、SHA-256、宽高与帧数。
- `LICENSE.txt`：逐图作者署名、许可名称及链接。

投稿者须拥有公开分发权，并明确同意 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)。不把代码的许可当成图片的分发许可。图片会重新编码以清除 EXIF、GPS、注释和尾部附加内容；动画保留渲染所需的帧与时长。

单图最多 8 MiB、2048×2048 像素、200 帧，累计解码像素最多 4000 万；图库当前最多收录 100 张、共 150 MiB。投稿校验失败时不收录。

维护者在合入前运行：

```powershell
python build/validate_community_stickers.py
```

发布前运行 `python build/update_plugin_manifest.py` 并提交清单，以保证所有发行包都按哈希安装素材。不要在投稿目录放脚本、账号、令牌、聊天记录或本机路径。

一键投稿使用投稿者自己的 GitHub 授权，仅写入独立的投稿分支并创建 PR；软件不携带维护者的账户令牌。不授权也可以使用导出 ZIP 的方式贡献。
