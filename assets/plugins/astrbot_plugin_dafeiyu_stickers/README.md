# 大肥鱼自动心情贴纸与素材库

附带开心、委屈、生气、害羞、晚安、喜欢六种原创透明 PNG，以及 24 张保留作者署名与许可的社区 GIF。它发送本地图片贴纸；原来的 QQ 表情文字转换继续负责 `[流泪]`、`[doge]` 等原生 QQ 表情段，两者互不替代。

插件总开关默认关闭。主动启用后，“自动匹配”默认开启、自动配图概率默认 35%：每条用户消息只抽样一次，模型仍可以不发，100% 也不强迫每句配图。桌面高级设置可关闭自动匹配、设置概率及 10–300 秒自动配图间隔，选择自然陪伴、活泼互动或仅应请求的场景，以及全部、原创、社区或个人图库。桌面尚未保存这些选项时，会保留 AstrBot WebUI 已保存的贴纸偏好。

模型接收有限的候选 ID、标题、标签、画面描述、适用与避用场景，结合已有上下文决定是否选图，而非只看到八个情绪词。不增加额外的识图、分类或向量模型调用。严肃求助、悲伤倾诉、任务操作、代码或链接答复不自动配图；轻松接梗、庆祝、问候与撒娇互动才可考虑，没合适素材就正常回文字。用户明确索要仍走独立发送工具。

桌面可导入 PNG、JPEG、WebP 与 GIF，填写标题、心情、标签、描述、适用/避用场景与署名，可逐张启停或删除。个人素材保存在 `data/plugin_data/astrbot_plugin_dafeiyu_stickers/custom`，不会进入软件资源包或自动上传 GitHub。每张最多 8 MiB、边长最多 2048、动画最多 200 帧且总解码像素最多 4000 万，个人图库最多 100 张、150 MiB。导入与导出都会逐帧解码并重新编码，清除 EXIF/GPS、注释和非图像载荷，保留 GIF/WebP 动画所需的时长与循环信息。不接收网址、可执行文件或任意磁盘路径。

个人素材只在当前文字模型请求的候选中提供用户填写的文字描述，不把私人图片文件自动上传给模型。明确导出只包含选中图片和允许公开的说明字段；公开投稿需另行确认分发权与许可，个人导入不代表同意公开。审核后随正式版本发行的投稿归“社区投稿精选”，保留逐图署名及 CC BY-NC 4.0 许可，所有下载用户均可使用；私人图库开关不影响已审核社区素材。

实现使用请求内的有限心情候选和内部标记，再在最终回复装饰阶段追加一张经过校验的本地图片；不会更改原生 QQ Face、代码块、行内代码或链接。工具回合、定时任务、机器人自身、非 QQ 平台不自动加图，已经使用发送工具的回复不会重复加图。

插件启用后，在 QQ 发送 `/肥鱼表情` 查看列表，发送 `/肥鱼表情 开心` 查看一张。对话中自然索要表情，模型也可调用 `send_dafeiyu_sticker`。如果大肥鱼刚刚发过表情并提议“再来一张？害羞的怎么样～”，紧接着回复“可以呀”或“你发”也能承接害羞的表情，无需重复固定口令。提议限同一真实 QQ 会话、同一发言者、两分钟以内的相邻下一轮；过期、否定或中间换了话题不会触发。插件重载后的私聊只从宿主本轮提供的、身份与时间匹配的最后一条对话恢复提议，不读取其他会话。

只回应当前收到的 QQ 会话；聊天白名单仍由宿主 AstrBot 管理。每条回复最多一张，自动配图默认间隔 30 秒；明确索要或确认近期提议时，成功发送后单独节流 3 秒，避免被自动间隔挡住。若送达不确定，会保留完整冷却并提示先检查 QQ，防止重试导致重复图片。不接受外部图片网址、文件路径或收件人，不扫描私人图片，也不下载用户提供的图片入库。

素材与固定目录、文件名、尺寸、SHA-256 清单一起分发。桌面素材库只展示随附图片，无须启用发送能力即可预览。

自有部分非商业许可及署名要求见项目 `LICENSE`、`NOTICE`。社区素材来源、作者网站及非商业分享许可见 `vendor/nekowhale/ATTRIBUTION.md`、`LICENSE-ASSETS` 等原文；社区内容不改为本项目自有许可。

自动按情绪搭配及文字标记的产品方式参考 [dsh-meme](https://github.com/yyh-001/dsh-meme) 的功能说明。本适配器为 AstrBot 重新实现，不运行 DeepSeek Harness 插件，不含其图库学习、任意网址下载或图库市场功能。

触发策略研究及原始资料见 [SOURCES.md](SOURCES.md)。所有新增适配代码独立实现，未复制其他表情插件代码。

## 1.3.0 图库整理与主动问候共用选图

- 批量选择最多20张图片，或导入普通未加密ZIP；逐张报告新增、重复复用或无效。重复图片保留现有说明和停用状态，不会重新启用。路径穿越、链接、加密文件、异常压缩比及容量超限会在写入前拒绝。
- 支持按名称、标签、画面说明和署名搜索，收藏及最近实际使用排序。收藏用于整理和同等匹配时的偏好，不会覆盖严肃场景的避用规则。
- “本地试选”根据文字标签和已明确反馈排序，不上传图片，不调用模型，也不发QQ。它展示候选，实际聊天仍由当前模型决定是否配图。没有视觉模型参与时，不会把文件名推测说成已经识图。
- “这张不合适”针对所选场景降低自动选图优先级，可清除；不会因为用户没回消息而推测不喜欢某张图。状态仅保存图片ID、收藏、时间/次数、场景和哈希会话范围，不保存试选文字或原始QQ标识。
- 主动问候也可通过 `proactive_context`、`prepare_proactive`、`revalidate_proactive`、`acknowledge_proactive` 使用同样的候选、概率、场景、真实图像校验与回执规则。不会构造虚假的用户事件；调用方负责真实主人私聊、会话总权限与发送历史。最终图片包发出前重查同一预留、开关、图库选择和实际图片，使等待期间的停用、删除立即生效；中途取消释放尚未发送的预留，结果未知保留冷却。
- 独立社区素材更新只接收官方正式发布中的 `community-stickers-manifest.json` 和对应ZIP；先展示变化，用户选择后再更新图片、说明与原许可，既不更新Python代码也不启用插件。当前随附素材已包含的图片不会要求重复下载。更新前检查官方发布的SHA-256、清单、全部图片实际格式/尺寸和逐图许可，通过后原子切换版本，失败保留原图库。

维护者用 `python build/build_sticker_materials.py --version 1.0.0` 生成公开数据包，将清单和ZIP上传到本仓库正式Release。原始社区GIF沿用 `LICENSE-ASSETS` 的非商业分享及保留作者链接要求，不把它们重新标成CC许可；原创和用户已审核投稿分别保持自身许可。
