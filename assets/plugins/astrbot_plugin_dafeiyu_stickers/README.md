# 大肥鱼自动心情贴纸与素材库

附带开心、委屈、生气、害羞、晚安、喜欢六种原创透明 PNG，以及 24 张保留作者署名与许可的社区 GIF。它发送本地图片贴纸；原来的 QQ 表情文字转换继续负责 `[流泪]`、`[doge]` 等原生 QQ 表情段，两者互不替代。

插件总开关默认关闭。主动启用后，“自动匹配”默认开启：模型可根据当前 QQ 聊天的气氛，给正常回复搭配一张合适的图片，无需每次明确索要。桌面“表情素材库”可关闭自动匹配、设置 10–300 秒会话间隔，以及选择全部、原创或社区图库。

实现使用请求内的有限心情候选和内部标记，再在最终回复装饰阶段追加一张经过校验的本地图片；不会更改原生 QQ Face、代码块、行内代码或链接。工具回合、定时任务、机器人自身、非 QQ 平台不自动加图，已经使用发送工具的回复不会重复加图。

插件启用后，在 QQ 发送 `/肥鱼表情` 查看列表，发送 `/肥鱼表情 开心` 查看一张。对话中明确要求“发一张害羞的大肥鱼贴纸”等，模型也可调用 `send_dafeiyu_sticker`。

只回应当前收到的 QQ 会话；聊天白名单仍由宿主 AstrBot 管理。每条回复最多一张，同一会话默认间隔 30 秒。不接受外部图片网址、文件路径或收件人，不扫描私人图片，也不下载用户提供的图片入库。

素材与固定目录、文件名、尺寸、SHA-256 清单一起分发。桌面素材库只展示随附图片，无须启用发送能力即可预览。

自有部分非商业许可及署名要求见项目 `LICENSE`、`NOTICE`。社区素材来源、作者网站及非商业分享许可见 `vendor/nekowhale/ATTRIBUTION.md`、`LICENSE-ASSETS` 等原文；社区内容不改为本项目自有许可。

自动按情绪搭配及文字标记的产品方式参考 [dsh-meme](https://github.com/yyh-001/dsh-meme) 的功能说明。本适配器为 AstrBot 重新实现，不运行 DeepSeek Harness 插件，不含其图库学习、任意网址下载或图库市场功能。
