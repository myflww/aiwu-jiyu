# 大肥鱼生活能力

随爱屋及鱼预装的独立插件。三个能力开关默认关闭：网页搜索、机器人QQ资料、机器人QQ空间。只接受已配置主人的真实QQ私聊，不把白名单或群管理员权限扩大成账号管理权限。QQ工具也遵守AstrBot当前配置的plugin_set和每会话插件禁用；不会用工具重新注入绕过会话开关。

开启网页搜索后，可以问“大肥鱼，查查这个梗是什么意思”。默认 Bing RSS 无需额外API Key；结果附真实网页标题、摘要和来源链接。需要其他来源时，可配置启用了JSON格式的公开HTTPS SearXNG服务。本插件不自动复制聊天记录、读取浏览器登录状态或借用对话模型密钥。

开启资料能力后，可请她准备昵称、签名、自定义在线状态，或从六张随附大肥鱼图片中选头像。她先列出机器人小号、旧内容、新内容；主人下一条独立消息回复 **确认这次修改** 才执行。头像不接收任意文件路径或网址。

自定义在线状态由一句单行文案和微笑、奋斗、睡觉、咖啡四种基础图标之一组成。它会将小号切到在线的自定义状态，预览会明确说明；这是在线状态，不是兴趣标签或签名。固定图标来自本机NapCat4.18.42内嵌face_config的QSid事实，不接收模型给出的任意数字ID。QQ客户端或协议端拒绝时会如实报告，不承诺所有账号都能显示。

开启QQ空间后，可请她准备纯文字说说。预览包含完整正文与可见范围，默认仅自己可见；主人回复 **确认发布这条动态** 才执行。这是QQ空间，不是微信朋友圈，不授予手机系统权限。个人资料标签尚无已核验的接口，需在QQ官方客户端管理。

每次准备有效10分钟，绑定主人、机器人账号和真实私聊会话。同一会话有多条待确认时，简单确认短句会拒绝执行；先取消多余准备，或使用那条预览附带的 `/鱼确认 <draft_id> <confirmation_token>`。取消尚未执行的准备可用 `/鱼取消 <draft_id>`。取消不能撤回已经完成的账号修改或动态。

只有准备工具向模型开放；不存在模型可调用的“确认执行”工具。成功、拒绝、接口不可用和结果未知分别报告。超时、断开或进程退出时不自动重发；请先到机器人小号核对。资料重读一致才标“已核验”；只有成功回执时不会宣称所有客户端都已显示。QQ空间需要返回真实说说标识。

程序和插件共享本机SQLite准备与回执记录，确认先用事务领取一次性准备，再请求QQ。没有保存QQ密码、cookie、搜索词历史或整段聊天记录。搜索使用5秒最短间隔与每UTC日60次上限，供轻量公开查询；返回最多6条摘要、响应最多512 KiB、网络socket超时8秒。这些是工程限额，不是论文推导的最佳参数或平台服务承诺。

实现、来源和验证范围见项目文档 `docs/联网搜索与机器人QQ资料.md`。本插件为原创适配代码，遵循随附非商业许可；没有复制NapCat、AstrBot或SearXNG的实现代码。
