# 上游来源与许可

本应用把以下开源项目组合成一个本地运行时：

| 组件 | 来源 | 许可 |
|---|---|---|
| AstrBot | https://github.com/AstrBotDevs/AstrBot | AGPL-3.0-or-later |
| NapCat | https://github.com/NapNeko/NapCatQQ | 见上游仓库 |
| 大肥鱼人格 / face_convert 插件 | https://github.com/whyever77/dafeiyu-astrbot | MIT |
| pywebview | https://github.com/r0x0r/pywebview | BSD-3-Clause |
| uv | https://github.com/astral-sh/uv | Apache-2.0 / MIT |

`LICENSE-dafeiyu-astrbot.txt` 是 whyever77/dafeiyu-astrbot 的 MIT 许可证原文，随人格与插件一起保留。

如果要把打包后的应用对外分发，请先确认 AstrBot 的 AGPL-3.0 义务（提供对应源码/修改）以及 NapCat 的许可与使用条款。仅自己本机使用不涉及这些分发义务。
