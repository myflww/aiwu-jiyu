# 1.6.0：节奏交给小鱼

设置里的“自然动态”是推荐模式。无需填写等待、概率和冷却：程序结合这轮是否说完整、连续发言的间隔、人格卡和近期表达状态决定接话时机。固定等待保留，选择“即时回应”则不人为追加收集时间。模型计算、联网、工具和QQ传输本身的耗时不在这几个开关控制范围内。

完整问题、短碎片、继续补充、改口、认真工作、倾诉和急事分别处理。连续输入仍保留原文、顺序、图片和引用，不先调用额外模型摘要。每轮有硬上限，后来发来的短句不能无限延长等待；正式说明不能被最后一句“嗯”改成闲聊分条。发新消息时停止尚未发出的旧回复，已被QQ接受的消息不能撤回。

五张人格卡提供不同的基础表达倾向。近期交流只形成短时、可衰减的表达状态：需要安静倾听时收起玩笑，谈正事时保持清楚完整，轻松时才活泼。它不是心理诊断或真实情绪，不会因为用户没回复、反驳或不喜欢某个称呼而故意冷落、拖延或要求道歉。自定义人格没有可核验的卡片节奏时采用中性的自然档。

群聊默认“自然参与”：明确被邀请时接话；刚得到她实际回复的同一成员，可以短时继续相关追问，不必每句都@。换人、另开话题、@别人和群里热闹起来时会收紧跟随。没有实际发送成功，就不开启跟随窗口。它不按随机概率抢答全群，也不把不同群友的话拼成同一个人的意思。还可选择“只在叫到时回应”和“安静陪群”；后者只认实际@或引用。原有群白名单、会话停用和独立工具授权始终有效。

高级设置保留旧版固定秒数、容量和light兼容选项。最近决策只显示原因、等待和所用人格，不展示聊天正文、QQ号或会话标识。没有在线心跳就不宣称规则正在生效。

## 研究与适用边界

- [Lin等，Wait, I'm Still Talking!，2002.09616v4](https://arxiv.org/abs/2002.09616v4)直接讨论人在一轮里连续发短消息，以及先决定等待还是回答。页面指出此为后续Predict-then-Decide工作的旧版本。本项目借鉴问题拆分，没有复制神经模型、训练数据或宣称复现其效果。
- [Jang等，TimelyChat / Timer，2506.14285v1](https://arxiv.org/abs/2506.14285v1)将时间语境与回复内容一起考虑。它的事件时间评测不能直接推出QQ应等几秒，本项目没有使用其训练模型。
- [MaiBot官方聊天与回复排查](https://docs.maibot.chat/faq/chat-and-reply)强调检查适配器回声及输入在推理期间的处理。这里以已安装的AstrBot 4.29.4真实流水线为准，不叠加另一套机器人框架或发送器。

动态阈值是可解释的产品默认值，未经真人大样本实验验证为“最像人”。本轮验证重点是实际等待随情景变化、同成员跟随、权限、去重及真实消息包；自然度仍受模型能力和已有上下文影响。验证不向真实QQ发送测试消息，不替用户发布账号动态，也不调用付费聊天模型。
