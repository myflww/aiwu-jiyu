# 高级陪伴与表情投稿

适用于爱屋及鱼 1.3.2。所有入口都在“插件百宝箱”；插件可独立开启，保存某项偏好不会替你打开宿主插件。

## 让大肥鱼自己来找话题

打开“主动陪伴与情绪”的陪伴设置，开启“让她主动来找你”，选择机会安排并保存。如果状态提示等待会话，在 QQ 与她私聊一句即可确认联系目标。AstrBot 和 QQ 连接正常运行时，后台每分钟检查一次，无需另外创建 cron 任务。

“固定机会间隔”使用你填写的分钟数；“随机机会区间”会在最短、最长间隔之间抽取下一次机会，并保存在本机。**机会到来不等于一定发送**：还要通过安静时间、概率、未回应、预算、免打扰及当前会话状态；模型也可能选择暂不打扰。

### 填入 Aurabot 参考值

按钮只填表，点击“保存设置”后才应用。参考值来自核对过的 [Aurabot 配置代码](https://github.com/aureth-labs/dsh-aurabot-qq/blob/b3301f6b014016e141c07d266a716c0fea566aab/src/core/config.js)：

| 项目 | 参考值 |
| --- | --- |
| 机会方式 | 随机 |
| 最短／最长机会间隔 | 60／180分钟 |
| 距主人私聊至少安静 | 40分钟 |
| 每日主动生成预算 | 4次 |
| 免打扰 | 23:00–08:00，本机时区 |

这些是上游开发者的配置选择，不是本项目做过实验后得到的最佳频率。Aurabot 的[普通主动调度](https://github.com/aureth-labs/dsh-aurabot-qq/blob/b3301f6b014016e141c07d266a716c0fea566aab/src/features/companion.js)没有基础概率衰减规则。本版的触发概率、百分比衰减和未回应暂停是独立选项；参考按钮会保留它们及其他能力开关的当前选择。

未回应暂停对照了 [AstrBot 主动消息插件](https://github.com/Pancakes-Labs/astrbot_plugin_proactive_chat/blob/95f459ef33208aa2c123c733ba1b5d2188dd0977/core/features/gating_feature.py)，互动结果影响概率的思路对照了 [chat_plus](https://github.com/Him666233/astrbot_plugin_group_chat_plus/blob/aa97e0e35a18733e73db753238dd2a3021446e42/utils/proactive_chat_manager.py)。本版按现有 AstrBot、NapCat 和爱之屋流程独立适配，没有复制这两个 AGPL 项目的代码。完整来源及默认值差异见 [陪伴插件来源说明](../assets/plugins/astrbot_plugin_dafeiyu_companion/SOURCES.md)。

### 自己调节高级设置

展开“高级调度 · 概率与未回应减扰”：

| 设置 | 怎么理解 |
| --- | --- |
| 私聊至少安静 | 与机会间隔同时满足；0表示不增加这一层等待。 |
| 机会基础概率 | 每次机会掷一次概率，未命中不调用模型、不占生成预算；0停止主动生成。 |
| 每次未回应后概率降低 | 例如50%，下一次有效概率再乘一半；0关闭衰减。 |
| 连续未回应后暂停 | 达到设置次数后等待主人私聊，聊一句恢复；0不限制。送达不确定也保留一次，避免反复发送。 |
| 无主人私聊后暂停 | 超过设定天数暂停；0不限制。 |
| 每日生成预算 | 0–20次，0不调用模型。模型选择沉默、生成失败或送达未知仍保留已经占用的名额。 |
| 免打扰与时区 | 可用本机时间、北京时间或UTC；开始与结束相同表示不设免打扰。每日预算也按所选时区计算。 |

旧版保存的固定间隔和每日次数会保留，不会自动替换成参考值。没有机会方式字段的旧设置按固定模式迁移；新增的安静时间、概率衰减和未回应暂停限制保持关闭，等你自行选择。

状态里的“下一次机会预估”用来判断调度是否在运行，不承诺必发。展开“查看自主机会与发送记录”，可看到后台机会、概率落空、生成结果和累计主动发起。**“适配器已接受”只表示发送调用已获接受，不表示主人已读**；送达未确认时不会立即重发。请根据这些实际记录、自己的聊天偏好和 API 预算调节。

## 找到本地后台的登录信息

在“本地后台”卡片点击 AstrBot 或 NapCat 旁的“登录信息”。面板默认收起；密码和 Token 默认遮住，可按需显示或复制，再打开对应后台填写。

- AstrBot 展示账号，以及能与当前本机配置核对的初始密码。若密码已修改或无法核验，请使用你自己设置的密码；软件不会从哈希还原新密码，也不会自动重置。
- NapCat 使用 **WebUI Token** 登录，没有单独的登录账号。这不是 QQ 密码、模型 API Key，也不是让你填写 OneBot 连接凭据的入口。

读取登录信息不会替你发起后台登录；收起后不会把凭据常驻展示在页面上。

## 导入自己的表情包

打开“大肥鱼表情包”，展开“高级设置 · 我的表情包与社区投稿”，点击“导入自己的表情包”。

1. 选择本地 PNG、JPEG、WebP 或 GIF，填写表情名称和主要心情。
2. 填写关键词、画面说明、“适合什么时候发”和“什么时候不要发”。例如：适合“被夸奖、分享好消息”，避免“对方难过、认真求助”。这些说明帮助模型匹配场景，不保证每次都选中。
3. 点击“保存到我的图库”，之后可以编辑、停用或移除。只保存在本机；导入不会自动公开投稿。

每张不超过8 MiB、边长不超过2048像素，动画最多200帧并有总解码像素限制；图库最多100张、总容量150 MiB，文字清单也有容量限制。导入时会重编码，去除 EXIF、GPS 和注释，支持范围内的动画会保留。

导入、编辑、停用和删除立即保存；自动配图、冷却和素材选择等选项仍需点击弹窗底部“保存设置”。

## 用自己的 GitHub 账号投稿

投稿是公开分享，先选择一张个人表情，填写“公开作者署名”，点击“预览投稿内容”。确认展示的图片、说明和署名，再勾选公开分发权与许可同意。

投稿素材采用 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)：可按许可进行非商业分享和改编，需保留适当署名、许可链接并标明修改。请只确认你确实有权按此许可公开分发的内容；项目自有代码及其他随附素材仍遵循各自许可。

### 连接账号

在“GitHub 账号”中填写**你本人的 personal access token（classic）**，当前流程使用公开仓库范围 `public_repo`，无需授予完整私有仓库 `repo` 权限。`public_repo` 是 GitHub 的公开仓库权限范围，不是只对一个仓库的授权。外部贡献者向不属于自己的公开仓库贡献时，fine-grained PAT 仍有使用限制；具体以 [GitHub 官方说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)和[权限范围说明](https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/scopes-for-oauth-apps)为准。

默认只在本次软件进程中使用授权。勾选“在此电脑加密记住授权”时，使用 Windows DPAPI 加密保存到本机当前用户环境；令牌不会写入投稿文件。点击“断开授权”可清除软件保存的授权；要撤销 GitHub 端令牌，可在 GitHub 的令牌设置中删除。

### 提交与审核

点击“一键投稿到 GitHub”后，普通贡献者会使用本人公开 Fork 中的独立分支，向 [myflww/aiwu-jiyu](https://github.com/myflww/aiwu-jiyu) 创建或复用公开 Pull Request。不会直接改主分支。提交前会核对分支差异，只允许预览里的三个新增文件：

```text
assets/plugins/astrbot_plugin_dafeiyu_stickers/community/submissions/<内容指纹>/
  image.png（或 image.jpg、image.webp、image.gif）
  metadata.json
  LICENSE.txt
```

它们分别是清理过元数据的图片、公开场景说明和署名、许可文件。不会夹带本地路径、聊天记录、软件配置或 GitHub 令牌。图片、说明或署名发生变化，需要重新预览和确认。

维护者审核收录并发布后，素材才会随之后的软件版本预装，供其他用户选择启用。提交 PR 本身不等于已收录，也不会立即改动其他用户的图库。

## 不连接 GitHub，也能导出投稿包

预览并确认相同的公开许可后，点击“导出投稿包”下载 ZIP。里面仍是上面的三个文件，无需在软件中填写 GitHub 令牌。你可以解压后按原目录上传到自己的 Fork，再手动创建 PR，等待维护者审核。
