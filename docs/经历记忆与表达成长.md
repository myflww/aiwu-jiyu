# 经历记忆与表达成长（1.6.0）

“成长”在这里指有来源、能纠正和能暂停的表达调整。它不代表真实意识、人格诞生或模型权重训练，也不把助手的猜测升格为用户事实。学习仍只作用于已登记的主人 QQ 私聊，不扩大群聊、电脑或机器人账号权限。

## 先修检索，再谈成长

这次审计以本地 `love-house` 仓库的精确 `v0.10.2rc1` 标签为旧版本依据；该仓库当前代码已是 `0.10.4rc1`，两者没有混用。没有读取真实聊天正文、私人记忆节点或调用模型来“验证记得住”。不能据此断言某一条历史聊天的具体丢失原因。

旧 AstrBot 桥的 `read_material` 固定申请 6000 字符，只送 `memory_context`。原服务另外返回的同会话 `history/messages` 没有被这条链路使用。旧服务选择中包含长期基线；结构化包先容纳人格资料，再逐条加入完整记录。长档案与完整对话的元数据会占预算，候选记录可能整体省略；泛泛的问题又容易命中基线。因此“只翻到我是什么样的人”有检索、排序和预算方面的可解释机制，不能只归因为模型额度，更不能假装把全库都看过。

新桥先进行一次最多 16000 字符的本地读取。只有原包明确截断，或“那个呢／后来呢”等短指代能得到同会话线索时，才进行第二次最多 24000 字符的读取。每轮最多两次本地记忆 HTTP 请求，不触发新的整理模型或后台反思模型。

最终送入现有回复请求的 JSON 不超过 12000 字符：相关命中的当前有效记忆优先，历史人格置后，只保留状态与较短的完整手动参考；同会话最近最多两组完整问答另标为历史证据，最多约 1600 字符，已在记录中的完整问答不重复。容不下的记录整条省略，明确计数；不截掉否定或更正的后半句。`records` 为空只说明这轮没有取到，不代表库为空。助手历史原话也不代表用户已经确认。

短指代补全只使用返回值中与当前哈希会话严格匹配的最后两条用户原话作为检索线索，不混入其他会话，不把助手上次的推测当事实。可选扩读失败会保留第一个有效包；身份或库变化则拒绝使用。来源库字段实时读取已登记配置，整次操作固定到开始时的库，防止换库过程中串接。

## 两条不同的学习路径

**明确反馈直接生效。** 只识别少数明确的低影响表达偏好，例如“少反问”“别开玩笑”“等我说完”“简短点”“少发表情”，以及对应明确的反向表达。引用、转述、条件句、双重否定和无法确定的说法不猜。代码只存结构化枚举、命中短句、来源事件／输入摘要的哈希；不复制整份聊天记录。最近一次明确反向反馈替代旧偏好。暂停后恢复自然默认；若已有新的明确选择，恢复旧记录也不能覆盖它。“先听我说完”只是有边界的表达／等待偏好，不会变成永久拒绝回复。

**模型反思始终保留为推测。** 在已有正常主对话内，`dafeiyu_reflect_experience` 可引用本轮实际召回的 1 至 5 条有效证据，提交不超过 300 字的简短推测与改进摘要。不存在另起的付费后台反思任务；不保存隐藏思维链。助手自己的输出、角色扮演、已失效／停用记录和群成员的外部发言不能冒充主人证据。

模型可附一个代码限定的语气枚举：简短一点、先听完、少逗趣、少反问、少自动表情。只有当前有效用户证据支持、没有已明确表达的相反选择时，才获得最多一小时的短期语气试行资格。试行每次仍须本轮召回同一证据并匹配内容摘要，用户反馈优先；试行期不等于实际采用，更不证明已经改进成功。自由文本 `next_step` 仅供界面查看，不执行，也不注入为指令。

推测可以在成长手记中查看、核对、暂停和恢复。手动核对也不会把它变成用户事实：后台只读一次有界的当前原库图检查原证据；更正、停用、忘记、来源内容变化或本轮没有相同证据时，不沿用旧推测。记忆事实与更正关系继续由爱之屋维护，成长手记不是第二个聊天数据库。

每条真实用户输入最多一个提案，提案至少间隔 10 分钟、每日最多 3 条，本地总记录有界。这些是可测试的保守产品预算，不是论文给出的最优频率。暂停不会假装删除原始记忆，也不延长试行到期时间。

用户明确确认忘记原始记忆前，会先清理该库全部成长推测／改进摘要／试行以及反馈命中原句，保留纯表达枚举与来源哈希，其他库不变。这一范围在确认页说明。清理使用 SQLite secure-delete 和 WAL 检查点，失败会阻止后续原始忘记操作，不会假报全部完成；若随后爱之屋忘记失败，成长派生正文已经清理，原记忆仍可重新预览处理。库级清理代次让另一个进程中的旧事件证据与旧工具循环缓存立即失效；清除私文不会重置提案防重放预算。

## 接口与边界

- `GET /api/growth` 只返回开关、连接状态、计数与限制说明，没有记忆库路径、原句或推测正文。
- `POST /api/growth/inspect` 在本机严格来源校验后查看当前账号与已绑定库的手记；不接受任意账号、库或路径参数。
- `POST /api/growth/mutate` 需要具体条目、当前 `revision`、明确 `confirmed:true` 与操作。并发变化后要求重新查看，不自动重发。
- `growth_enabled` 独立控制学习；关闭不自动开启／关闭活动感知、主动聊天或其他权限，旧手记保留可查看。
- SQLite 只记录有限的表达偏好、短推测与证据标识／哈希，拒绝链接、重解析点、硬链接和超限文件。没有模型 Key、平台令牌或私人运行路径出现在公开状态中。

## 研究依据与实现取舍

[Generative Agents（Park 等，2023）](https://arxiv.org/abs/2304.03442)把观察、反思与计划区分开，并让反思指回具体经历。本实现借鉴证据引用，增加推测标记与撤回，没有照搬论文中的自动反思阈值、递归强化或额外生成频率。

[MemGPT（Packer 等，2023／2024）](https://arxiv.org/abs/2310.08560)强调有限工作上下文与外部存档之间的明确移动。本实现采用有界资料包，不把“已存档”说成“每轮都已经进入模型上下文”。

[LongMemEval（Wu 等，ICLR 2025）](https://arxiv.org/abs/2410.10813)将索引、检索与阅读拆开评估，覆盖时间、知识更新和未知时不编造；其研究显示，整轮粒度与多线索索引有帮助，过度压成事实会丢失细节。本实现保留完整证据、有限同会话线索与当前更正优先，采用合成样例检查，不声称已经通过完整基准或保证真实会话的记忆准确率。
