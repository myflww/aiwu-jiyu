# 大肥鱼陪伴与表情插件的兼容适配

图中项目使用 DeepSeek Harness 的接口；爱屋及鱼使用 AstrBot、NapCat 和爱之屋。本次把所需能力适配为随下载包附带的 AstrBot 插件，保留现有账号、记忆和插件开关。

| 参考项目 | 在爱屋及鱼中的位置 | 已提供的能力 |
| --- | --- | --- |
| [dsh-aurabot-qq](https://github.com/aureth-labs/dsh-aurabot-qq) | 主动陪伴与情绪 → 陪伴设置 | 主人私聊的主动问候、频率上限、免打扰和情绪上下文 |
| [dsh-whale-musume-persona](https://github.com/Kaalia0912/dsh-whale-musume-persona) | 陪伴设置 → 鲸鱼娘口吻增强 | 傲娇但温柔的自然中文表达，减少固定欢迎词和客服收尾，保留实际工具能力 |
| [dsh-nekowhale-stickers](https://github.com/Loping151/dsh-nekowhale-stickers) | 大肥鱼表情包 → 配图与素材 | 二十四张精选原始社区动图，离线附带，保留作者、站点及角色设计者署名 |
| [dsh-meme](https://github.com/yyh-001/dsh-meme) | 大肥鱼表情包 → 按聊天情绪自动配图 | 文本模型按心情选择本地图片，由 QQ 回复适配器发送；支持间隔和原创/社区图库选择 |

这不是在 AstrBot 中直接执行 DSH 插件。适配器独立实现，不引入第二套 QQ 桥接或替换爱之屋。上游的其他社交平台、语音、翻唱、桌宠界面和图库市场不属于本次圈出的能力，也未被默认启用。

两个新插件首次安装默认停用，用户可分别启用。主动聊天、鲸鱼娘口吻、情绪表达和活动感知另有独立开关；表情插件启用后默认允许适量自动配图，每条回复最多一张，默认间隔三十秒，也可关闭自动匹配并明确请求发送。

素材共有三十张：六张项目原创 PNG、二十四张社区 GIF。社区图像按 `dsh-nekowhale-stickers` 的 `LICENSE-ASSETS` 非商业分享条件附带原图和署名，未修改图像；其元数据与代码许可范围分别保留。`dsh-meme` 当前默认图片包清单另标 `personal`，没有把代码的 MIT 许可当成图像再分发许可，因此未复制那套图片。

固定上游提交、原始许可、资源哈希和作者链接见：

- `assets/plugins/astrbot_plugin_dafeiyu_companion/SOURCES.md` 与 `references/`
- `assets/plugins/astrbot_plugin_dafeiyu_stickers/vendor/nekowhale/ATTRIBUTION.md`、`provenance.json`、`community-catalog.json`
- 根目录 `THIRD_PARTY_NOTICES.md`

1.3.1 的行为修复还核对了 AstrBot 的[分段回复文档](https://docs.astrbot.app/use/webui.html)与[原生表情组件被拆成独立消息的问题](https://github.com/AstrBotDevs/AstrBot/issues/10047)。自然分段由独立的 AstrBot 兼容模块实现，不替换框架发送管道；原生分段已经开启时让出发送权。仅对合适的自然聊天长文分成有限的几条消息，保留技术内容和发送去重。

自动配图仍遵守用户设置的间隔；用户明确点图或接受她刚提出的表情邀请，使用单独的短间隔保护。发送结果不确定时保留冷却，避免重复发送。主动聊天在面板显示实际运行条件和下一次机会，不依赖模型自述判断是否工作。
