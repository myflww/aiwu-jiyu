# 爱屋及鱼 1.5.0

## 先让她听完

在设置的“连续消息与发送节奏”打开收集。默认从最后一条消息起等10秒；中途补发就重新计时，连续输入最多等待30秒。默认达到12条或6000字也会结束等待，整条原消息不会被截掉。它保留原文、顺序、图片和引用，不先调用模型把用户的话有损概括。

这些数字是用户提出后采用的可调整默认值，没有研究证明它们适用于所有人。可以调到1–30秒或关闭收集，最长等待设为5–120秒且不小于单次等待。命令、紧急请求以及原生流式等不适合收集的输入按真实规则绕过。

合适的日常回答可以变成2–4条完整短消息，有独立意思再分，不把一句话切成几个词。正式要求、代码、表格、工具结果和完整文稿保持整体。旧版本把 Pydantic 消息浅复制，可能导致所有包都变成最后一段；这次用真实 AstrBot 发送阶段复现并修正。

整条明确说“不用回复”“先不聊了”时，可以自然结束；不会把“好”“可以”“收到”一律当成不需要回复，因为它们也可能是确认。此时原始输入保存到 AstrBot 的真实用户历史，没有伪造助手答复。目前爱之屋来源协议不提供 user-only 归档类型，所以不把这类结束语冒充已整理记忆，也不制造永远等待助手内容的整理项。

## 群里有分寸

在聊天权限页设置群规则。默认只回应实际 @ 她、引用她，或明确用唤醒名称叫到她的消息。@全体不是 @ 她。不同成员分别收集，不把两人的话拼成一个人的意思。

轻度参与要另行选择，仍需要相关唤醒，默认最多每小时6次、间隔90秒、参与机会3%；0次表示不开轻度参与。明确叫到她的消息不消耗轻度参与预算。它不会替代群名单，也不会给群友开放主人记忆、电脑或QQ账号权限。

全新安装默认启用“对话节奏与陪伴”的基本收集和群规则；主动问候、活动感知和情绪等仍分别选择。已有明确停用的插件保持停用。插件总开关关闭后，这里的规则不会假装仍在运行；保存偏好可热读取，不必为普通节奏调整重启整套服务。

## 五张完整人格卡

设置里有自然朋友、经典肥鱼、温柔陪伴、元气搭子、冷静学伴。每张都有性格、相处方式、语言节奏、群聊与正式场景约定和示例，可以先查看完整文本。

应用时需要对话服务运行，程序只更新原生“大肥鱼”人格的提示词。先保留原人格备份，相同内容不重复备份；聊天、长期记忆和原工具选择保留。恢复时同样先备份当前内容。若另一个后台窗口改了人格，旧页面会要求刷新；原生接口没有事务ETag，两个外部窗口在同一瞬间修改仍可能后写覆盖，建议一次使用一个编辑窗口。

三个预设参考了明确许可的社区完整资料后重新适配，其余两张为本项目原创。来源、版本和许可随包附带，不把五张卡宣称为全网热度排名。[研究与来源](人格卡与对话机制.md)。

## 用真实图片表达

大肥鱼表情包插件继续独立启用。模型可在当前主请求里选一张或明确不配图；没有精确标记时，程序可在双方文字确实支持的问候、庆祝、轻松互动等场景保守选图。鱼 emoji 不等于图片，也不作为兜底依据。严肃倾诉、正式工作、冷却、概率、个人停用与“不合适”反馈继续生效，并避免紧接着重复上一张。

在“配图与素材”的“最近为什么没有发图片”查看真实原因：没有抽中、正在冷却、场景不合适、模型弃选、无可靠匹配、素材不可用、发送未确认等。不会为了检查而自动发测试图片。发送调用完成也不代表对方已读。[实现依据](自动表情可靠性研究与实现.md)。

## QQ生活与搜索

六个插件均预装。QQ生活与联网搜索首次默认关闭，可以分别选择搜索、机器人资料和空间能力。作用对象是已经连接的机器人 QQ 小号，不是主人的主号、手机操作系统或微信。

- 搜索：默认使用 Bing 公开RSS，无需额外搜索Key；也可配置自己的公开HTTPS SearXNG JSON搜索服务。只传明确关键词，结果带真实链接；公开服务可能限流或改变格式，失败会说明，不把空结果编成资料。
- 机器人资料：昵称、个性签名、六张随附头像，以及带基础图标的自定义在线状态。在线状态会切为在线；它与个人兴趣标签不同。兴趣标签未找到已核验接口，需在QQ官方客户端管理。
- QQ空间：可以准备纯文字说说，默认仅自己可见，也可在预览时选择好友或公开。不是微信朋友圈，执行还要检查实际NapCat接口和登录账号。

设置中先保存能力开关。可以在软件里填写并预览，也可以让 QQ 里的她准备；核对实际小号、头像、文案和可见范围后确认。QQ中可说“确认这次修改”或“确认发布这条动态”，只对应当前会话唯一未过期的待确认内容；有多个草稿时会要求选定，不能替另一人或另一会话确认。

成功、平台接受、明确拒绝、不支持、结果未知分开显示。未知结果不会自动重发；要先检查实际QQ。准备能力不等于已经修改账号，验证中没有替用户改头像、签名或发布动态。[接口与权限说明](联网搜索与机器人QQ资料.md)。

## 更新与体验

软件版本为1.5.0。图片数据仍为1.4.0，图片和许可没有变化，不会因为更新程序就重复下载素材。已有模型Key、QQ登录、记忆库和设备授权保持各自存储位置。

自动化测试和真实 SDK 验证可以确认消息顺序、不同实际消息包、去重、媒体生命周期、权限、API回执和故障处理；不能保证某个模型每轮都像真人。人格和语气仍取决于模型与实际上下文。复杂任务可以完整说清，普通聊天可以短一点，也可以自然结束。
