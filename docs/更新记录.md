# 爱屋及鱼 1.3.1 · 让聊天接得上

- 修正记忆小屋的小爱心轮廓；聊天权限中的人数与单位统一基线和间距，窄窗口也完整显示。
- 陪伴设置显示主动聊天的真实运行状态、会话连接、下一次机会与今日次数；区分插件启用和具体能力开启，无需另设 cron 任务。
- 表情插件能承接她刚提出的表情邀请后的“可以呀”“你发”；明确点图与自动配图分别节流，保留发送去重和失败状态。
- 新增可选自然分段回复：合适的长聊天回答分成 2–4 条，支持偶尔或经常发送；代码、链接、工具结果和短句保持完整，新消息到来可停止旧回复的后续分段。
- 未在桌面保存过偏好时保留 AstrBot 插件页原有配置，避免启动软件把用户选择恢复为默认。
- 打开软件后检查软件与随附插件的正式发布版本，有更新时合并弹窗提醒；可以稍后处理或前往更新，下载、校验和安装仍由用户决定。其他自行安装的插件在 AstrBot 后台管理。
- 插件版本落后但软件同版时，可下载经过校验的同版安装包修复；更新了正在使用的随附插件后会重载对话服务，避免文件已更新却仍执行旧代码。

# 爱屋及鱼 1.3.0 · 更会陪伴，也能动手

- 插件页新增 AstrBot、NapCat 本地后台快捷入口，随服务状态更新。
- 诊断日志自动维护：启动及每十分钟检查，空闲时超过 5 MiB 保留最新 1 MiB，连续七天未写入清空。
- 随包新增可选“主动陪伴与情绪”和“大肥鱼表情包”，六张原创贴纸与二十四张社区授权动图离线预装。支持按聊天语气自动匹配图片，新插件默认停用，已有选择继续保留。
- 陪伴能力可分别开启：主动聊天、模拟情绪、前台应用/闲置概况；默认两小时一次、每日三次和夜间免打扰，仅联系已建立私聊的主人。
- 参考 Aurabot、鲸鱼娘人设和两类 DSH 表情插件完成 AstrBot 兼容适配，口吻增强可选；不新增 QQ 桥接，不覆盖现有人格与爱之屋记忆，素材保留来源和各自许可。
- 最高电脑权限新增真实 Windows 桌面工具，并修复模型无法发现授权工具的问题。桌面权限单独开启，仅限真实 QQ 私聊，管理员按项授权。

# 爱屋及鱼 1.2.1 · 把回忆捧在手心

- 记忆小屋加入爱之屋的红色像素爱心与大肥鱼捧心插画，更清楚地呈现本机爱之屋、记忆库和 QQ 会话之间的关系。
- 首次设置的模型页和日常设置页新增 DeepSeek API Key 官方平台快捷入口，在默认浏览器打开，返回后可继续填写。
- 延续 v1.2.0 的插件开关、内存统计、立绘切换和可选更新机制。

# 爱屋及鱼 1.2.0 · 一键领养大肥鱼

- 插件页改为紧凑列表，每个插件都有独立启停开关。状态保存到本机；支持热切换时立即应用，需要重启时会明确提示。
- 首页直接显示系统物理内存、应用各组件占用及最近一分钟趋势，每两秒采样。修复 Windows 64 位进程内存读取与父进程归属。
- 移除各页大段介绍横幅、重复的记忆步骤条和重复入口；权限弹窗直接显示有效设置。
- 新增日常手绘、蓝白水手、水手 Q 版立绘，保留经典 Q 版，可在设置中切换。
- 增加“一键领养大肥鱼”介绍页、使用说明及贡献指南。

**下载与安装**：首次使用可选 Windows x64 安装程序；便携版完整解压后运行“爱屋及鱼.exe”。需要 Windows 10 2004 或更新版本、QQ 小号、DeepSeek API Key 和网络。长期记忆另需安装本机爱之屋。

**升级**：账号、Key、记忆库及运行数据与程序分开保存。更新控制台不等于关闭聊天服务。旧版正在运行的对话服务首次切换插件后，可能需要点击“应用更改 · 重启对话”。
