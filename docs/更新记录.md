# 爱屋及鱼 1.4.0 · 让陪伴连成日常

- 主动问候接入已登记主人会话的共同流程：使用实际启用的记忆／表情插件，检索已有经历与待跟进约定，同一次模型请求选择表情，按需自然分段；只把获适配器接受的文字前缀写入真实会话和来源队列。新消息、停用、取消与未知送达不会触发补发，未发送的图片预留会释放；图片包发出前再次核对实际开关与资产。主动流程保持无工具权限。
- 记忆小屋新增同一本爱之屋库的真实条目目录、分页搜索、来源与原文查看、更正、重要标记、停用／恢复，以及用户明确登记的事实、偏好和约定。永久忘记先展示原文、派生、复制记录与本库旧备份范围，再确认；管理过程沿用原库，不新增另一份完整聊天记忆库。
- 新增安静陪伴、自然朋友、活泼陪伴三档和自定义高级参数；首页支持临时安静／更多机会／恢复平时，也可用明确的主人私聊句式调整，两处“今天”的调整均在所选时区当天结束。临时“更多机会”保留原每日预算和免打扰，普通聊天继续响应。主动调用显示已报告用量与未报告次数，不猜测实际账单。
- 首页和诊断日志新增只读“小家体检”，分开显示开关、监听、QQ 登录、模型配置、任务心跳、记忆和权限等证据，并给出固定入口指引。检查不发送测试 QQ、不调用聊天模型，也不会把配置可读取当作已验证余额或实际送达。
- 作品箱新增真实电脑工具步骤与结果：显示进行中、完成／未完成、实际命令退出码及可打开的作品。工具步骤完成与整个任务完成分开；超过6分钟缺少完成回执显示“结果未确认”。电脑授权继续独立管理。
- 更新安装前或手动操作可制作最近5份有限范围恢复点，仅保存允许的非敏感偏好与逐文件匹配清单的随包插件。同版本、服务关闭且明确确认时可恢复；跨版本先下载校验并由用户安装匹配旧版，再按该版本已有能力处理设置。账号、密钥、权限、聊天、记忆及个人图库不进入此恢复点。
- 表情库新增最多20张批量导入／受限ZIP、精确图片去重、搜索、收藏、最近使用、本地场景试选与可撤销的不合适反馈；试选只列文字标签命中项，文件名标签草稿明确不识图、不调用模型。社区素材通过官方正式发布单独预览和更新图片／说明／原许可，不替换代码。六张自有表情采用白衬衫配铅笔裙与黑色连裤袜、黑色针织修身裙、青绿旗袍、黑夹克配格纹裙、碎花裙、针织开衫六种衣橱设定，二十四张社区GIF保留原图及原许可。新增连接、工作、翻看回忆、安静陪伴、修复五张 image_gen 状态插画，并据真实状态解释造型。

参数说明：自然朋友的60–180分钟、安静40分钟、日预算4沿用核对后的Aurabot配置；安静180–360／日2、活泼30–90／日6及反馈衰减是可调整的产品规则。论文为记忆分层、连续性和减少打扰提供设计参考，没有证明本软件这些分钟数最优，也没有将隔离测试当成真实用户陪伴效果实验。

操作见 [1.4.0 使用指南](1.4.0使用指南.md)，设计与验证见 [陪伴连续性](陪伴连续性研究与实现.md)、[自检恢复与操作记录](自检恢复与操作记录.md)、[表情图库研究](表情图库研究与实现.md)，美术来源与提示词摘要见[状态插画清单](../assets/ui/states/artwork-manifest-v140.json)。

# 爱屋及鱼 1.3.2 · 自己安排陪伴节奏

- 陪伴设置新增固定/随机主动机会、私聊安静时间、触发概率、未回应概率衰减与暂停、时区、每日生成预算和会话有效天数。预算设为0时不调用模型；已有显式设置继续保留，不自动改成新预设。
- 增加“填入 Aurabot 参考值”：随机60–180分钟、私聊安静40分钟、每天4次、23:00–08:00免打扰。经固定提交的代码核对，这些只是上游配置参考，不是实验验证的最佳值；概率和未回应减扰为独立可调选项，填入后保存才生效。
- 主动聊天状态显示下一次机会预估、有效概率、连续未回应次数、后台触发来源和发送回执。概率落空不消耗模型预算；适配器接受不等于主人已读，送达未知时保留名额避免重发。
- AstrBot、NapCat 本地后台入口增加默认收起的登录信息，可按需显示和复制；NapCat 使用 WebUI Token。AstrBot 只展示能与当前配置核对的初始密码，改过的密码不做猜测或重置。
- 表情包高级设置支持导入本地 PNG、JPEG、WebP、GIF，编辑心情、关键词、画面说明、适用及避免场景，并独立启停。图片重编码去除 EXIF、GPS 和注释，动画在限制内保留。
- 新增公开表情投稿：预览图片、说明和授权三个文件，填写署名并确认 CC BY-NC 4.0 许可后，可使用本人的 GitHub classic PAT（`public_repo`）创建 Fork、独立分支和 PR；可选 Windows DPAPI 本机记住授权。由维护者审核收录后随之后版本预装，不直接改主分支。
- 未连接 GitHub 或授权不可用时，可导出相同内容的 ZIP 投稿包，按目录手动提交审核。

详细操作与来源见 [高级陪伴与表情投稿](高级陪伴与表情投稿.md)。
