# 爱屋及鱼 1.2.1 · 把回忆捧在手心

- 记忆小屋加入爱之屋的红色像素爱心与大肥鱼捧心插画，更清楚地呈现本机爱之屋、记忆库和 QQ 会话之间的关系。
- 首次设置的模型页和日常设置页新增 DeepSeek API Key 官方平台快捷入口，在默认浏览器打开，返回后可继续填写。
- 延续 v1.2.0 的插件开关、内存统计、立绘切换和可选更新机制。

# 爱屋及鱼 1.2.0 · 一键领养大肥鱼

- 插件页改为紧凑列表，每个插件都有独立启停开关。状态保存到本机；支持热切换时立即应用，需要重启时会明确提示。
- 首页直接显示系统物理内存、应用各组件占用及最近一分钟趋势，每两秒采样。修复 Windows 64 位进程内存读取与父进程归属。
- 移除各页大段介绍横幅、重复的记忆步骤条和重复入口；权限弹窗直接显示有效设置。
- 新增日常手绘、蓝白水手、水手 Q 版立绘，保留经典 Q 版，可在设置中切换。
- 增加“一键领养大肥鱼”介绍页、使用说明及贡献指南。

**下载与安装**：首次使用可选 Windows x64 安装程序；便携版完整解压后运行“爱屋及鱼.exe”。需要 Windows 10 2004 或更新版本、QQ 小号、DeepSeek API Key 和网络。长期记忆另需安装本机爱之屋。

**升级**：账号、Key、记忆库及运行数据与程序分开保存。更新控制台不等于关闭聊天服务。旧版正在运行的对话服务首次切换插件后，可能需要点击“应用更改 · 重启对话”。
