# NapCat 下架与连接恢复

适用于爱屋及鱼 1.6.3，核查日期：2026-11-17。

**原来已安装、能正常聊天的用户无需重装。** 本版继续使用个人 QQ 小号，通过 NapCat 与 AstrBot 收发私聊和群聊；保留原来的运行数据目录、QQ 登录状态、名单、插件和爱之屋记忆连接，不做账号或数据迁移。

## 发生了什么

NapCat 的[官方仓库](https://github.com/NapNeko/NapCatQQ)现在只保留结束说明；[2026-11-12 的提交](https://github.com/NapNeko/NapCatQQ/commit/105f38e3ecb1428c147e0f9165f65f854233d988)将 README 改为“Ending / 到这里告一段落。”。[官方 Releases 页](https://github.com/NapNeko/NapCatQQ/releases)已没有发布产物，因此旧版安装器依赖的官方文件地址无法继续用于新装。

1.6.3 将下载来源改为 [XingYunStar/NapCatQQ 的 4.18.42 社区归档](https://github.com/XingYunStar/NapCatQQ/releases/tag/v4.18.42)。归档页明确说明保存的是上游历史发布产物。它不是 NapCat 官方维护渠道，爱屋及鱼也不是 NapCat 官方续作。

恢复下载只解决安装文件的获取。仍使用个人号协议，未来 QQ 更新、登录限制或账号风控可能影响使用；社区归档和固定校验值不能保证长期维护、永久兼容或永不封号。本版没有把个人小号改成 QQ 官方机器人。

## 已经装好的用户

升级爱屋及鱼程序后，继续使用原来的运行数据目录。在首页“一键开启”，确认对话服务在线、QQ 已登录，再测试私聊和群聊。

程序会复用已有完整 QQ 连接环境，不强制下载或重新登录。如果只是 QQ 登录授权失效，按首页提示重新扫码；重新导入安装包不会恢复已经失效的登录授权。

安装目录里的程序文件与运行数据可能分开。不要为了修复下载而删除 `runtime`、配置文件、爱之屋数据或整个数据目录。常用备份位置见[使用说明](使用说明.md#数据备份与卸载)。

## 新装与离线导入

正常安装会先确认 QQ 连接环境或原包是否已准备好，再安装其他运行环境。有效缓存会直接复用；需要下载时使用固定社区归档地址，并提供代理回退。

网络下载失败时：

1. 打开[社区归档发布页](https://github.com/XingYunStar/NapCatQQ/releases/tag/v4.18.42)，下载 **`NapCat.Shell.Windows.Node.zip`**。也可使用[该文件的固定下载链接](https://github.com/XingYunStar/NapCatQQ/releases/download/v4.18.42/NapCat.Shell.Windows.Node.zip)。
2. 保持原始 ZIP。不要解压后重新压缩，不要改用普通 Shell、Framework 或 OneKey 包。
3. 在首次安装向导或安装失败面板点击“导入离线连接包”；首页可从“运行与诊断 → QQ 连接包”打开相同入口。
4. 选择 ZIP，等待校验成功，再继续或重试安装。导入只准备缓存，服务仍按原来的设置启动。

如果在另一台电脑下载，可把原始 ZIP 复制到这台电脑后再选择导入。导入后的缓存位于当前运行数据目录的 `downloads\NapCat.Shell.Windows.Node.zip`，不要求你自己查找或搬动程序内部文件。


## 导入或安装失败时

| 提示或现象 | 处理方式 |
| --- | --- |
| SHA-256 不匹配、包布局不符 | 核对版本和 Windows Node 包类型，重新完整下载原始 ZIP；不要修改文件来绕过校验 |
| QQ 连接正在运行 | 已有环境正常时无需导入；确需准备原包时，先在首页“一键关闭”，等服务停止后操作 |
| 安装或导入正在进行 | 等当前操作结束再试，避免多个窗口同时安装 |
| 下载地址不可达 | 换可用网络，或在其他电脑下载后使用离线导入；保留日志中的错误原因 |
| 发现不完整的 QQ 连接目录 | 程序会保留现有目录，不自动覆盖；先备份运行数据，核对日志列出的缺失文件后再处理 |
| 原包已准备好，仍不能登录或收发 | 检查二维码授权、QQ 连接与对话服务日志、模型 API 和聊天名单；这不一定是下载问题 |

导入会先临时复制并校验，成功后才替换缓存；错误文件不会写入为有效原包。安装会先在临时目录检查，遇到已有不完整目录会停止并保留原内容。不要直接拿新的空配置覆盖旧环境。

排查时可以复制最近报错，并说明爱屋及鱼版本、Windows 版本、卡住步骤及是否已有可用环境。分享前去掉密钥、登录令牌、QQ 号码、聊天内容和个人路径。
