# 一键领养大肥鱼 · 使用说明

爱屋及鱼由 myflww 制作，用来管理 QQ 里的大肥鱼和本机服务。本说明对应 Windows 桌面版。

## 准备与安装

需要 Windows 10 2004（内部版本 19041）或更新版本 / Windows 11 的 64 位系统、可用网络、一个供大肥鱼使用的 QQ 小号，以及你自己的 DeepSeek API Key。QQ 主号用于和她聊天，不用于登录机器人。模型服务按提供方规则计费；软件不附送 API 余额。

从[官方发布页](https://github.com/myflww/aiwu-jiyu/releases)下载 Windows x64 包。完整解压后运行 `爱屋及鱼.exe`，不要直接在压缩包预览窗口里打开。包内的“安装到桌面.cmd”会将程序复制到当前用户的程序目录并建立快捷方式；发布页若提供安装程序，也可以按安装向导操作。

程序使用 Microsoft Edge WebView2 显示界面。缺少组件时会尝试准备；自动准备失败时，按提示安装[微软 WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)后重新打开。

### 完成首次设置

1. 选择运行数据目录。运行环境、配置、下载和日志都会放在这里，请留出足够空间并确保当前用户可写。
2. 等待运行环境安装完成。首次安装需要联网下载；窗口中的进度和日志可用于判断卡在哪一步。
3. 填写 DeepSeek API Key，选择 `deepseek-chat` 或 `deepseek-reasoner`。已有 Key 时，输入框留空会保留原值。
4. 手机 QQ 切换到小号，再扫描二维码。二维码过期会自动更新，也可以手动刷新。
5. 填写你用来和她聊天的 QQ 主号。这个号码会被认作主人，并加入私聊名单。
6. 完成向导，在首页确认 QQ 已登录、对话服务在线，再给小号发消息。

NapCat 使用个人号协议。首次启动若出现 Windows 防火墙提示，按安装提示允许所需的专用网络通信。

## 日常使用

| 操作 | 结果 |
| --- | --- |
| 首页“一键开启” | 启动对话服务和 QQ 连接；未完成设置时会先引导设置 |
| 首页“一键关闭” | 停止对话服务和 QQ 连接，控制台窗口保留 |
| 关闭窗口 | 正常情况下收进系统托盘，服务继续运行 |
| 托盘“退出应用（服务继续）” | 退出控制台，后台聊天服务继续运行 |
| 托盘“退出并停止服务” | 停止聊天服务并退出控制台 |
| 插件页“应用更改 · 重启对话” | 应用待生效的插件设置，短暂重启对话服务，保留 QQ 连接 |

设置中的“开机启动”会在登录 Windows 后将控制台启动到托盘。“记住已授权的 QQ 小号”用于尝试快速登录；授权失效时仍需扫码。

## 聊天名单与电脑权限

“聊天权限”页的“仅回应名单”开启后，只回应名单中的私聊和群聊；主人始终可以聊天。可直接输入号码添加，也可在 QQ 登录后刷新联系人，从好友和群中选择。添加一个群意味着群中成员可以唤醒她。

允许聊天不代表允许操作电脑。电脑操作默认关闭，需要使用时：

1. 在“插件百宝箱”启用“电脑操作”。
2. 点击该插件的“操作权限”，或从首页“运行与诊断”进入“设置权限”。
3. 选择工作目录，确认是否只允许私聊、命令超时等设置，阅读并确认授权后保存。
4. 需要让其他人操作时，在“聊天权限”中为对应私聊对象设置管理员，并分别分配读取、写文件和执行命令权限。

电脑操作命令以当前 Windows 用户权限运行，工作目录限制不等于操作系统沙箱。主人拥有该功能开放的全部操作权限，其他管理员按单独设置的权限使用。只想聊天时，保持电脑操作权限关闭即可。

## 插件开关

随包提供的插件有：

| 插件 | 作用 | 还需要什么 |
| --- | --- | --- |
| QQ 表情 | 将 `[流泪]`、`[doge]` 等标签转成 QQ 表情 | 对话服务在线 |
| 长期记忆 | 将登记的会话交给爱之屋保存、整理和召回 | 安装并启动爱之屋，连接记忆库和会话，配置整理模型 |
| 电脑操作 | 读写文件、运行任务 | 单独设置操作权限和工作目录 |

每个插件都有独立滑动开关；额外安装的插件列在“其他插件”中。停用插件会保留其配置与数据。

支持热切换时更改立即应用。出现“已保存，重启对话服务后生效”时，开关表示你保存的选择，正在运行的服务可能仍采用旧状态；点击“应用更改 · 重启对话”后再刷新确认。若重启后仍未加载，查看诊断日志。“插件维护”中可打开插件目录、修复记忆插件文件或重启对话服务。

## 连接长期记忆

爱之屋是独立的本地记忆服务，需要从[爱之屋发布页](https://github.com/myflww/love-house/releases)另行安装 Windows 版本。爱屋及鱼提供连接入口，不会自动保证已下载或安装爱之屋。

1. 安装爱之屋并打开一次。当前连接器会在 `%LOCALAPPDATA%\Programs\LoveHouse` 等固定位置查找 `LoveHouse.exe`；自定义放置的位置可能无法被识别。
2. 回到“记忆小屋”，点击“刷新”。若服务未运行，点击“启动爱之屋”；“打开爱之屋”可切换到独立窗口。
3. 在“记忆库”里选择已有库，或填写名称新建。不同库是独立存档，连接会固定到选中的库。
4. 在“登记 QQ 会话”区域填写会话标识 UMO，每行一个。默认会填主人私聊；需要登记其他会话时，在目标会话发送 `/sid`，将完整结果粘贴进来，不要只填 QQ 号或群号。
5. 点击“保存会话连接”。这会登记来源并配置插件，可能短暂重启对话服务；QQ 连接保留。
6. 打开爱之屋，在“记忆整理”里配置模型 API。对话归档成功后，还需要整理才能形成可召回的长期记忆。
7. 检查“连接状态”里的已保存轮数、待提交记录和错误信息；同时确认“长期记忆”插件已启用。

记忆只处理已登记的会话。显示“会话已连接”代表来源已登记，不等于已经产生记忆；显示“已保存对话”也不等于整理模型已经处理完。连接成功后先完成一轮新聊天，再检查归档和整理状态。

## 内存监测怎么看

首页直接显示系统物理内存的使用率、已用、总量和可用容量。首页可见时每 2 秒请求一次采样，折线保留本次打开界面期间最近 60 秒的读数；切换到其他页或隐藏窗口后，不保证持续记录走势。

“应用进程合计”将桌面界面、对话服务、QQ 连接和已识别的记忆服务分项相加。它统计进程工作集，与系统整体占用使用不同口径；其他软件、系统缓存也会使用内存，共享内存的统计方式还可能与任务管理器不同，不能用两个数字相减得出精确的剩余软件占用。

分项会包含识别到的服务子进程，并避免把同一进程重复分到多个组件。服务未启动时对应值可能为 0；读取失败显示“—”或“不可用”，不是伪造的占用率。记忆服务分项依赖识别到运行中的爱之屋窗口，未识别到时可能显示 0。

## 工作目录与作品箱

在“设置 → 工作目录”选择文件夹并保存。保存目录不等于开放电脑操作权限。

作品箱列出工作目录内可见的文件，按最近修改时间排序。可打开文件、在文件夹中定位，或直接打开工作目录。文件没有出现时，先核对生成位置是否属于当前工作目录，再点“刷新作品”。

## 立绘与其他设置

“设置 → 界面立绘”提供日常手绘、蓝白水手、水手 Q 版和经典 Q 版。点击立即切换，选择保存在本机界面存储中；清理界面存储或更换环境后可能恢复默认。立绘选择不修改聊天人格、模型或权限。

“对话模型”和“主人身份”需点击“保存对话设置”。保存会短暂重启对话服务，QQ 登录保持连接。API Key 留空保留原值；自定义模型服务地址在高级选项中设置。

“软件更新”可自动检查，也可手动检查。发现更新后由你选择下载、安装或忽略。安装前程序会校验下载包；仅检查版本不会自动替你安装。

## 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 界面提示连不上本机服务 | 确认控制台进程仍在，点击“立即重试”；若整个进程已退出，重新打开程序 |
| 环境安装卡住或下载失败 | 查看向导日志中的下载地址和报错，检查网络、磁盘空间与目录写入权限，再重试 |
| 二维码扫了仍未登录 | 手机是否切到目标小号、二维码是否过期；刷新二维码并检查 QQ 连接日志 |
| QQ 已登录但没有回复 | 检查对话服务状态、API Key 和模型余额、聊天名单、是否正在重启；在诊断日志查看具体错误 |
| 插件开关改了但功能没变化 | 是否显示待应用；应用更改后刷新。电脑操作还需授权，长期记忆还需连接爱之屋 |
| 没找到爱之屋 | 确认装的是 Windows 版且存在 `LoveHouse.exe`；按安装说明放到可识别位置，打开一次再刷新 |
| 爱之屋已连接但没有长期记忆 | 检查 UMO、当前记忆库、插件开关、归档轮数，以及爱之屋的整理模型 API 和整理结果 |
| 服务启动失败或端口占用 | 避免重复启动多份服务；在“运行与诊断”检查状态。对话服务使用 6185、QQ 连接使用 6099、OneBot 使用 6199；爱之屋通常使用 8768 |
| 内存数值不更新 | 保持首页可见，检查“采样中断”提示；重新连接本机服务后再观察 |

“诊断日志”按对话服务、QQ 连接分开显示，可刷新、跟随新记录或复制。提交问题时说明软件版本、Windows 版本、复现步骤和报错片段。请先去掉日志中的密钥、登录令牌、真实 QQ 号、聊天内容和个人文件路径，不要上传整个数据目录。

## 数据备份与卸载

程序文件与运行数据可能在不同位置。以首页“运行与诊断”显示的安装目录、设置里的工作目录和记忆页的数据目录为准。

| 内容 | 默认位置 |
| --- | --- |
| 桌面程序文件 | 桌面安装脚本使用 `%LOCALAPPDATA%\Programs\AiwuJiyu` |
| 爱屋及鱼数据与运行环境 | `%LOCALAPPDATA%\Dafeiyu`，首次设置可另选目录 |
| 自选数据目录的启动记录 | `%LOCALAPPDATA%\Dafeiyu\bootstrap.json` |
| 爱之屋记忆与控制器数据 | `%LOCALAPPDATA%\LoveHouse` |
| 作品文件 | 设置里选定的工作目录，默认在爱屋及鱼数据目录的 `workspace` 中 |

备份前先停止聊天服务并退出控制台，再在爱之屋中退出记忆服务，避免复制到正在写入的数据库。分别备份实际爱屋及鱼数据目录、爱之屋数据目录和独立工作目录；如果自选了数据目录，也保留上述启动记录。不要只备份程序 EXE。

备份包含登录状态、模型配置、聊天和记忆，应按私人数据保管。桌面配置中的 Key 使用 Windows DPAPI 加密；换电脑、重装 Windows 或更换用户后可能无法解密，需要重新填写 Key 和登录 QQ。服务运行所需的本地配置也可能含敏感信息，不能把备份公开发布。

卸载前先在设置里关闭“开机启动”，再使用托盘“退出并停止服务”；爱之屋需另外退出。通过安装程序安装的版本可在 Windows 应用列表卸载；便携或桌面脚本版本可删除程序文件及快捷方式。

安装程序没有主动清理运行数据、记忆和工作目录的操作。保留这些目录便于恢复；若要彻底移除，在确认备份可用后，由你手动删除对应的实际数据目录、启动记录和不再需要的作品。删除爱屋及鱼程序不等于卸载独立的爱之屋。
