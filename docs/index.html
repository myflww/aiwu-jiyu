开始使用

三步，接她回家。

查看完整使用说明 ↗
  1. 01

    下载 Windows 版

    到 GitHub 发布页下载 Windows x64 包，解压后打开“爱屋及鱼.exe”。

  2. 02

    连接模型和 QQ

    跟随首次设置向导填写 DeepSeek API Key，再用 QQ 小号扫码登录，并设置主人 QQ。

  3. 03

    去 QQ，打个招呼

    开启服务后发送消息。需要其他能力时，再到插件、记忆小屋和权限设置中配置。

爱屋及鱼是本地桌面控制台，不包含自训练模型。对话由你配置的模型 API 提供；长期记忆需连接本机爱之屋并完成整理配置。
